# 3D 粒子手势交互

摄像头识别手部骨骼，实时驱动 8 万个 3D 粒子。纯前端，无框架，依赖全部已本地化（**不联网也能跑**）。

## 启动

**日常就一个入口：桌面上双击 `3D粒子手势` 快捷方式**（它指向本文件夹的 `启动.cmd`）。

或者直接双击本文件夹里的 **`启动.cmd`**，浏览器会自动打开 `http://127.0.0.1:8765/index.html`。

- 会弹出一个黑色命令行窗口 —— 别关，它就是服务器；用完关掉它即停止。
- 窗口还开着时又双击一次也没关系：不会起第二个服务，只会把页面重新打开。
- 整个文件夹可以随便挪到别的盘/发给同事（快捷方式要重建），挪完双击 `启动.cmd` 照样能用。

> 为什么不能直接双击 `index.html`？
> 浏览器规定 `file://` 页面不允许调用摄像头，ES Module 也无法跨域加载。
> 所以必须走本地服务器（`localhost` 属于安全上下文，摄像头可用）。

手动启动：

```bat
node serve.mjs 8765      :: 首选
py -3 serve.py 8765      :: 没装 Node 时的备选
```

## 手势对照

| 手势 | 效果 |
| --- | --- |
| 移动手掌 | 旋转粒子云（带惯性） |
| 五指张开 | 粒子爆散、体积膨胀 |
| 握拳 | 粒子向中心聚合 |
| 拇指 + 食指捏合 | 镜头拉近 / 拉开（捏紧 = 靠近） |
| 手指张开度 | 花朵形态下 = 绽放度（张到七八成即满开） |
| 快速左右挥手 | 切换形态：球体 → 心形 → 银河 → 环结 → 花朵 |
| 双手开合 | 直接控制相机远近 |
| 食指指尖 | 推开附近粒子（局部力场） |

**花朵形态专属**：握拳 = 花苞合拢，张开 = 逐瓣绽放，手停在半开状态花就停在半开
（这个形态下“张开手”不再触发爆散，整个自由度让给绽放）。

花朵不是一张平面贴图：三层花瓣沿 z 方向叠出碗形纵深（内层朝镜头抬高、瓣尖向后收），
花蕊是朝向镜头的半球，再叠一层“离镜头越近越亮”的明暗，所以从正面看也有厚度。

没有摄像头或拒绝授权时，自动降级为鼠标模式：拖拽旋转 / 滚轮缩放 / 单击换形态 / 空格爆散 / 数字键 1–5 切形态 / R 复位。
鼠标模式下花朵会自动开合，方便演示。

## 视觉调参（想要更“高级”就动这几个数）

| 想要 | 改哪里 |
| --- | --- |
| 光晕更强 / 更弱 | `new UnrealBloomPass(..., 0.35, 0.40, 0.80)` 第 1 个参数强度 |
| 光晕更散 / 更紧 | 第 2 个参数半径（0.4 紧、0.8 散） |
| 只有最亮处发光 | 第 3 个参数阈值（调高 = 更克制） |
| 整体更亮 / 更暗 | `renderer.toneMappingExposure`（默认 1.0） |
| 粒子更亮/更淡 | 顶点着色器 `vAlpha = (0.13 + aRand * 0.30)` |
| 粒子更大/更小 | `uniforms.uSize`（默认 2.35） |
| 配色 | `SHAPES` 里每组 `c1`（内核色）/ `c2`（外缘色） |
| 远处更朦胧 | 顶点着色器 `fogK` 那段 `(depth - 24.0) / 70.0` |
| 花朵开合幅度 | 顶点着色器花朵那段 `0.46 + 0.54 * pB`（0.46 = 花苞有多小） |
| 花朵开合快慢 | `frame()` 里 `bloomVal += ... exp(-5.0 * dt)` 的 5.0（越大越快） |
| 花朵多容易开满 | `frame()` 里 `clamp((S.open - 0.08) / 0.70)`：把 0.70 改小 = 更容易开满 |
| 花朵纵深 | `buildFlower()` 每层 `zBase`（内层抬高）/ `curl`（瓣尖后收）/ `tilt`（每瓣侧翻） |
| 花朵明暗纵深 | 着色器 `flowerShade = mix(0.42, 1.00, ...)`：前亮后暗的强度 |
| 花瓣轮廓清晰度 | `buildFlower()` 里 `Math.pow(Math.abs(uRaw), 0.58)`，指数越小边缘粒子越密 |
| 花朵整体亮度 | `SHAPES` 里花朵那项的 `alphaMul: 0.56` |

> 注意：粒子是叠加混合（Additive），密度越高越容易烧成白色。觉得“糊成一团白”就先降 `vAlpha`，再提阈值。

## 调参指南

- **粒子数量 / 大小**：`app.js` 顶部 `COUNT`（默认 80000）、`uniforms.uSize`。
- **形态尺寸**：`RADIUS`（默认 6.2）。
- **形态切换时长**：`MORPH_TIME`（默认 1.15 秒）。
- **手势灵敏度**：
  - `measure()` 里的 `open` 映射区间 `1.15 ~ 1.73`（自然张手就到 1，不必把手撑到极限）。
  - 花朵绽放再映射一次：`clamp((S.open - 0.08) / 0.70)`，张到约 78% 就满开。
  - 捏合区间 `0.30 ~ 1.15`。
  - `applyHands()` 里 `S.yawT += dx * 6.4`（旋转跟随速度）。
  - 挥手阈值 `Math.abs(palmVX) > 1.05`（单位：屏幕宽度/秒）。
- **爆散强度**：`const burstTarget = clamp(S.open * 0.55 + burstKick * 0.35)`。
- **指尖力场**：着色器里 `exp(-dist2 / 9.0)` 控制作用半径，`uPtrForce` 控制强度。

## 调试

浏览器控制台：

```js
__app.S           // 实时状态：open / pinch / zoom / hands / label
__app.feed([lm])  // 注入合成手部骨骼（21 个 {x,y,z}），无摄像头时调参用
__app.gotoShape(4) // 0 球体 1 心形 2 银河 3 环结 4 花朵
__app.bloom        // 花朵当前的绽放度 0~1
```

## 性能

默认 60fps（120Hz 屏幕跟随刷新率）。若集显吃力，把 `COUNT` 降到 40000，或把 `renderer.setPixelRatio` 上限从 2 改为 1.5。
